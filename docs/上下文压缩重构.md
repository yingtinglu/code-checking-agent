# 上下文压缩重构（L2/L3/L4）

## 背景

原压缩方案三个问题：

1. **L2 只压纯文本轮**（`_l2_truncate_dialogs` 仅处理 user+紧随的无 tool_calls assistant）。本项目工具密集，多数轮含工具调用 → L2 空转，压缩负担全压 L3（丢）+ L4（摘要），损失大。
2. **L4 数据源是全量存储**，范围 > L3 丢完后的工作副本，且把 L3 丢的远古又捞回重摘要——与 L3 决策打架，结果可能压不下。
3. **L3 无限丢**，对上下文破坏太大。

## 目标

- L2 拓宽到**所有轮**，但**只压 user 文本 + assistant 最终回答文本**，**不碰工具结果**（L1 已投影，重要保真）。
- L3 **bounded 丢弃**，有上限，不无限丢。
- L4 **全量选择性摘要**：读全量存储，但摘要只留 user 需求/提问 + assistant 回答/结论主线（忽略工具 chatter），重要/不可复现工具结果提取为"关键事实"追加末尾。结果 compact → ≤ L3 工作副本，质量高。
- 级联 L2→L3(bounded)→L4(全量选择性)。L4 最后、少触发（耗算力）。

## 设计

### L1（不变）

大 tool result（>4000 token）落盘 artifact，上下文留投影。工具结果保真。

### L2' 拓宽（规则式，无 LLM）

`_l2_truncate_dialogs` 改为：对每个历史轮（cur_turn_start 之前），压缩：

- `user` 文本 → 截断保留首部 ~100 token。
- 该轮**最后的无 tool_calls assistant**（最终回答）→ 截断保留首+尾 ~150 token。
- **不动**：tool_calls 骨架、tool 结果投影、中间 assistant(tool_calls)。
- 跳过已摘要（`[历史对话摘要]` 标记）。

效果：工具密集轮的 user 描述 + assistant 结论（常是大头）被压，工具数据不动。廉价首轮，处理常见情况，少触发 L4。

### L3' bounded 丢弃

`_l3_drop_ancient` 加上限：从最旧轮起丢，降到 target **或** 只剩最近 K=3 轮就停（取先到者）。不无限丢，保近期真实历史给 L4。

### L4' 全量选择性滚动摘要

`_l4_full_summary` 重写：

- 数据源 `conversation.messages`（全量存储，不缩范围）。
- 渲染 `_render_history_for_summary`（已对 tool 结果降权：存档引用只标存在、投影取内容、无前缀截 500）。
  - **调整**：assistant 带 tool_calls 的，只取其最终回答文本，**工具调用名不进叙事**（避免 chatter 入主线）。
- 按完整轮次分块（`_chunk_messages_by_turn`，chunk_budget=30000，不切开 tool_call↔result 配对）。
- 滚动累积（`_rolling_summary`，oldest→newest）：每块产出**双输出**——
  - `[叙事]`：user 需求/提问 + assistant 回答/结论主线，忽略工具调用过程。
  - `[关键事实]`：重要/不可复现工具结果（具体数值、发现文件、关键数据点），bullet。
  - 与上轮 `[叙事]+[关键事实]` 合并，叙事 ≤~1500 token、关键事实 ≤~500 token。
- 最终 = `[历史摘要]\n[叙事]\n...\n[关键事实]\n- ...\n[/历史摘要]` + 当前轮原文（`_cur_turn_start` 后保护）。
- 失败回退 L3（`_l3_drop_ancient`）。

**≤ L3 约束**：L4 选择性输出（忽略工具 chatter，bounded ~2k），≪ L3 工作副本（含完整工具结果）。满足。

### 渲染调整

`_render_history_for_summary`（`:627`）：

- assistant 带 tool_calls：原 `助手(调用 工具名): content[:200]` → 改为只取 `content`（最终回答文本，若有），无则跳过（不把工具调用名当主线）。工具结果信息由 LLM 从 tool 消息自行判断提取为关键事实。

## 验证

1. 语法：`python -c "import ast; ast.parse(open('chat_agent/context.py',encoding='utf-8').read()); print('OK')"`。
2. L2' 单测：构造工具密集轮，断言 user/最终 assistant 文本被截断、tool 结果不动。
3. L3' bounded：构造超长历史，断言丢到只剩 K 轮就停。
4. L4' 滚动：mock LLM，断言滚动 N 块、双输出（叙事+关键事实）、忽略工具 chatter。
5. 端到端：跑长对话触发 L4，看 `[L4摘要后]` 降到 target 以下、摘要含 user/answer 主线 + 关键事实、当前轮完整。
